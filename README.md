
# 🚀 Python File Loaders & Processor

За основу данного приложения взято практическое упражнение из репозитория [Data Engineering Practice](https://github.com/danielbeach/data-engineering-practice/blob/main/README.md), на базе которого была спроектирована собственная модульная архитектура, добавлены различные стратегии параллелизма, автоматическая распаковка архивов и полноценный CLI-интерфейс[cite: 1].

Универсальное и отказоустойчивое приложение на Python для пакетной загрузки файлов из интернета, проверки их валидности, многопоточной/асинхронной обработки, последующей распаковки архивов и сравнения производительности (бенчмаркинга).

---

## 📋 О проекте и задачах

Основная цель проекта — изучить и реализовать на практике различные подходы к сетевому вводу-выводу (**I/O-bound** задачи) в Python на примере скачивания и обработки архивов с данными (например, наборов данных Divvy Trips).

### Что было сделано:
1. **Общий абстрактный фундамент (`BaseFileDownloader`):**
   * Применен паттерн проектирования *Шаблонный метод (Template Method)*.
   * Вынесена вся общая рутина: валидация URL (защита от пустых строк и *Path Traversal*), проверка существования файлов (кэширование), создание папок и перехват сетевых ошибок.
2. **Четыре стратегии загрузки:**
   * **`thread`** — многопоточная загрузка через `ThreadPoolExecutor` и `requests` (с контролем `max_workers`).
   * **`async`** — высокопроизводительная асинхронная загрузка через `asyncio` и `aiohttp`.
   * **`requests`** — простой последовательный синхронный загрузчик.
   * **`wget`** — загрузчик на базе внешней утилиты `wget` с выводом прогресс-бара.
3. **Продвинутая проверка ответов:**
   * Предварительные `HEAD`-запросы для определения размера файла (`Content-Length`).
   * Проверка заголовков `Content-Type` на наличие HTML-страниц с ошибками (защита от сохранения битых заглушек).
4. **Менеджер архивов (`ZipExtractor`):**
   * Автоматический поиск `.zip` архивов, их распаковка в целевую директорию и безопасное удаление оригиналов для экономии места на диске.
5. **Бенчмарк производительности (`benchmark.py`):**
   * Автоматическое тестирование и сравнение скорости всех четырех методов скачивания.
6. **Удобный CLI (Интерфейс командной строки):**
   * Управление через подкоманды (`download`, `extract`, `clean`, `benchmark`) с подробной встроенной справкой (`--help`).
7. **Полная изоляция через Docker:**
   * Конфигурация через `Dockerfile` и `docker-compose.yml` с поддержкой монтирования томов (`volumes`) для сохранения файлов на хост-машину.

## 🕹 Использование (CLI Команды)

Приложение управляется через `cli.py`. Вы можете передавать собственные списки ссылок или использовать встроенные по умолчанию.

### 1. Скачивание файлов

Доступны методы: `thread`, `async`, `requests`, `wget`.

* Скачать дефолтные файлы многопоточно (по умолчанию, в 3 потока):
```bash
python cli.py download --method thread

```


* Скачать свои ссылки асинхронным методом:
```bash
python cli.py download --method async [https://example.com/file1.zip](https://example.com/file1.zip) [https://example.com/file2.zip](https://example.com/file2.zip)

```


* Посмотреть справку по аргументам скачивания:
```bash
python cli.py download --help

```



### 2. Распаковка архивов

Находит все загруженные архивы, распаковывает их в папку `divvy_extracted` и удаляет оригиналы:

```bash
python cli.py extract

```

### 3. Запуск бенчмарка скорости

Замеряет и выводит в лог итоговую таблицу времени скачивания всеми четырьмя способами:

```bash
python cli.py benchmark

```

### 4. Очистка диска

Удаляет все папки с архивами, распакованными данными и кэшем бенчмарков:

```bash
python cli.py clean

```
