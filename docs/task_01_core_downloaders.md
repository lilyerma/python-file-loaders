# Задача 1: Базовый загрузчик и стратегии I/O

### 1. Постановка задачи
За основу данного приложения взято практическое упражнение из репозитория [Data Engineering Practice](https://github.com/danielbeach/data-engineering-practice/blob/main/README.md). Требовалось спроектировать собственную модульную архитектуру для пакетной загрузки файлов из интернета, реализовать различные стратегии параллелизма и ввода-вывода (**I/O-bound**), а также добавить автоматическую проверку файлов и CLI-интерфейс.

### 2. Что было сделано

#### А. Шаблонный метод (`BaseFileDownloader`)
В модуле `downloader_pkg/base.py` был спроектирован абстрактный базовый класс с использованием паттерна проектирования **Шаблонный метод (Template Method)**:
* **Валидация путей и URL:** Проверка на пустые строки и попытки выхода за пределы директории (*Path Traversal*).
* **Кэширование/Проверка:** Пропуск скачивания, если файл уже существует локально и не пуст.
* **Управление окружением:** Автоматическое создание целевых папок через `pathlib`.
* **Перехват ошибок:** Централизованная обработка таймаутов, сетевых сбоев и недоступных ресурсов.

#### Б. Четыре стратегии загрузки
На базе общего фундамента реализованы конкретные реализации загрузчиков в пакете `downloader_pkg/`:
1. **`requests_loader.py` (Синхронный):** Классический последовательный загрузчик через библиотеку `requests`.
2. **`thread_loader.py` (Многопоточный):** Параллельная загрузка списка файлов с использованием `ThreadPoolExecutor` и настраиваемым параметром `max_workers`.
3. **`async_loader.py` (Асинхронный):** Высокопроизводительный асинхронный подход с использованием `asyncio` и `aiohttp`.
4. **`wget_loader.py` (Внешняя утилита):** Делегирование скачивания системной утилите `wget` с отображением встроенного прогресс-бара.

#### В. Продвинутая проверка ответов
* Предварительные `HEAD`-запросы для проверки размера файла (`Content-Length`).
* Анализ заголовков `Content-Type` для предотвращения сохранения HTML-страниц с ошибками (404/500 заглушек вместо бинарных файлов).

### 3. Как использовать

Запуск скачивания определенным методом через единый CLI-интерфейс:

```bash
# Многопоточная загрузка (по умолчанию)
python cli.py download --method thread

# Асинхронная загрузка пользовательских ссылок
python cli.py download --method async [https://example.com/file1.zip](https://example.com/file1.zip) [https://example.com/file2.zip](https://example.com/file2.zip)
