# Задача 2: NOAA Parser & Pipeline

### 1. Постановка задачи
Для автоматизированного сбора, обработки и анализа климатических данных с открытого ресурса NOAA был спроектирован и реализован специализированный модуль `noaa_loader.py`. Требовалось объединить веб-скрапинг страниц NOAA, выборочное скачивание файлов через наши сетевые загрузчики, а также последующий анализ температурных показателей.

### 2. Что было сделано
* **Веб-парсер на BeautifulSoup:** Реализован поиск и извлечение ссылок на файлы данных с учетом конкретных временных меток (таймстампов) на страницах NOAA.
* **Интеграция с загрузчиками:** Связка с `RequestsFileDownloader` для надежного скачивания найденных архивов/файлов с обработкой сетевых ошибок.
* **Анализ данных (Pandas):** Встроенный обработчик для чтения структурированных данных и поиска целевых показателей (например, максимальных значений `HourlyDryBulbTemperature`).
* **CLI-интеграция:** Добавлена новая подкоманда `noaa` в главный интерфейс `cli.py`, позволяющая запускать полный цикл сбора и анализа одной командой.

### 3. Как использовать

Запуск пайплайна NOAA через командную строку:
```bash
python cli.py noaa
