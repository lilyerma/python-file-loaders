# Задача 6: Модульный PySpark аналитический пайплайн

В рамках данной задачи реализован распределенный аналитический пайплайн на базе **Apache Spark** для обработки архива данных (Divvy Trips).  [Источник задачи](https://github.com/danielbeach/data-engineering-practice/blob/main/Exercises/Exercise-6/README.md)

---

## 🏗 Архитектура решения

Пакет `pyspark_task/` разделен на логические слои, обеспечивающие независимость загрузки данных, оркестрации и аналитических расчетов:

1. **Инициализация сессии (`spark_session.py`)**:
   * Настройка и запуск локальной `SparkSession` с оптимизациями под запуск в контейнеризированной среде (Docker) с поддержкой Java JDK.
2. **Ингестация и предобработка (`ingestion.py`)**:
   * Распаковка целевых ZIP-архивов во временную директорию.
   * Чтение сырых CSV-файлов через `Pandas` с последующей конвертацией в PySpark DataFrame.
   * Первичная очистка данных «на входе» (удаление разделителей тысяч в строках вроде `2,818.0`, нормализация типов).
3. **Оркестрация и трекинг (`analytics.py`)**:
   * Последовательный запуск аналитических запросов (`q1.py` – `q6.py`) с детальным логированием времени выполнения, подсчетом строк и сохранением результатов в формате CSV.
4. **Изолированные аналитические модули (`queries/`)**:
   * Каждое бизнес-требование вынесено в отдельный модуль (`q1.py`, `q2.py`, ... `q6.py`), принимающий DataFrame и возвращающий агрегированный результат.

---

## 🔍 Описание аналитических запросов (Q1–Q6)

* **`q1.py`**: What is the average trip duration per day? (Средняя длительность поездки по дням).
* **`q2.py`**: How many trips were taken each day? (Количество поездок по дням).
* **`q3.py`**: What was the most popular starting trip station for each month? (Самая популярная стартовая станция для каждого месяца).
* **`q4.py`**: What were the top 3 trip stations each day for the last two weeks? (Топ-3 стартовых станций за каждый день последних двух недель).
* **`q5.py`**: Do Males or Females take longer trips on average? (Сравнение средней длительности поездок по полу: мужчины или женщины).
* **`q6.py`**: What is the top 10 ages of those that take the longest trips, and shortest? (Топ-10 возрастов с самыми длинными и самыми короткими поездками).

## 🛡 Обработка краевых случаев и ошибок Spark

При работе с реальными датасетями Divvy были решены следующие типичные проблемы PySpark:

1. **Отсутствие Java (`JAVA_GATEWAY_EXITED`)**:
   * Добавление `default-jdk` в многоэтапный `Dockerfile` гарантирует наличие стабильного окружения JVM для работы Spark-моста.
2. **Маскированные числовые поля (`CAST_INVALID_INPUT`)**:
   * Использование безопасного приведения типов через **`try_cast`** и предварительная очистка строковых чисел в Pandas предотвращают падения при встрече с запятыми-разделителями или некорректными символами в колонках вроде `tripduration`.
3. **Арифметические переполнения и `NaN` (`CAST_OVERFLOW`)**:
   * Использование функций `isNotNull()` и **`isnan()`**, а также фильтрация аномальных значений возраста позволяют избежать ошибок при попытке перевести нечисловые артефакты `NaN` в целочисленные типы (`INT`).
